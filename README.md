# 盆栽自动浇灌系统

[English](./README.en.md)

这是一个基于 Arduino 的自动浇灌项目，用于盆栽土壤湿度监测、水箱水位告警、弱光保护和 OLED 状态显示。项目硬件接口说明见 [接口文档.md](./docs/接口文档.md)。

文档中提供的Woiki参考较久，且部分硬件与实际硬件不符，仅供参考。

## 功能概览

- 自动读取土壤湿度，土壤过干时启动水泵浇水。
- 读取水箱水位，水量不足时停止水泵，避免水泵空转。
- 水位偏低时通过 LED 和蜂鸣器进行间断告警。
- 环境光过低时停止浇水，并忽略水量不足告警。
- OLED 显示当前植物模式、系统模式、光照值、土壤湿度值和水箱状态。
- 按键 1 切换植物模式，按键 2 切换系统模式。

## 硬件组成

- Arduino Uno 或兼容开发板
- 土壤湿度传感器
- 光照传感器
- 水位传感器
- 0.96 寸 SSD1306 OLED 显示屏
- 有源蜂鸣器模块
- 继电器模块
- 5V水泵
- LED 和限流电阻
- 两个按键
- 面包板和杜邦线

## 引脚连接

详看接口文档

| Arduino 引脚 | 外设         |
| ---------- | ---------- |
| D2         | 按键 1       |
| D3         | 按键 2       |
| D4         | 工作指示 LED   |
| D5         | 有源蜂鸣器      |
| D6         | 继电器 IN     |
| A0         | 光照传感器 AO   |
| A1         | 土壤湿度传感器 AO |
| A2         | 水位传感器 S    |
| A4         | OLED SDA   |
| A5         | OLED SCL   |

继电器控制水泵电源，程序中 `LOW` 表示继电器吸合、水泵启动，`HIGH` 表示水泵关闭。

## 程序逻辑

程序在 `loop()` 中持续读取光照、土壤湿度和水位传感器数据，并根据当前状态决定是否浇水、是否告警以及 OLED 显示内容。

传感器读数约定如下：

- 土壤湿度读数越大，表示土壤越干。
- 光照读数越大，表示环境越暗。
- 水位读数越小，表示水箱水量越少。

核心阈值集中定义在 `template.ino` 顶部：

| 常量                       | 作用          |
| ------------------------ | ----------- |
| `LIGHT_NEED_IRRIGATE`    | 光照判断阈值      |
| `HUMIDITY_NEED_IRRIGATE` | 土壤干燥判断阈值    |
| `NO_WATER_LEVEL`         | 水箱严重缺水阈值    |
| `LOW_WATER_LEVEL`        | 水箱低水位告警阈值   |
| `PUMP_WORK_TIME`         | 单次水泵工作时间    |
| `IRRIGATE_COOLDOWN`      | 两次浇水之间的冷却时间 |

## 按键说明

| 按键   | 功能     |
| ---- | ------ |
| 按键 1 | 切换植物模式 |
| 按键 2 | 切换系统模式 |

OLED 默认字库对中文支持有限，因此程序界面使用英文标签显示模式和状态。

## 使用方法

1. 在 Arduino IDE 中安装依赖库：`Adafruit GFX Library` 和 `Adafruit SSD1306`。
2. 按照 [接口文档.md](./docs/接口文档.md) 完成硬件连接。
3. 打开 `template.ino`，选择 Arduino Uno 或兼容开发板。
4. 编译并上传程序。
5. 根据实际传感器读数调整阈值常量。

## 注意事项

- 有源蜂鸣器模块可能存在高电平触发或低电平触发差异，如果蜂鸣器状态相反，可以调整 `BUZ_ON` 和 `BUZ_OFF`。
- 水泵建议使用独立电源供电，开发板只负责通过继电器控制通断。
- 首次接入真实传感器时，应先观察 OLED 上的原始读数，再调整阈值。
